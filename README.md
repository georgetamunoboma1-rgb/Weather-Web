# Weather Web App 🌦️

A clean and responsive weather application built with vanilla web technologies.

## 🚀 Features
* Real-time weather data via OpenWeatherMap API.
* Responsive design for mobile and desktop.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Flexbox)
* JavaScript (ES6+ Fetch API)
